First modern return and continuity after return

Separate analytical preview. Main figures retain exactly the established complete-follow-up actionable ending cohorts (Ethiopia 1,799; Nigeria 1,607; DRC 797); appendix figures select the earliest eligible ending per woman before assessing follow-up outcomes.

The first curve follows endings for up to twelve months to a first modern return. The second starts at that return and follows up to twelve subsequent months. It therefore can extend beyond the original ending’s twelve-month endpoint. The first-return curve has complete twelve-month follow-up after the original ending. The continuation curve starts a new clock and can be censored at the last eligible calendar month when twelve additional months after return are unavailable. Pregnancy is not censored in the first-return analysis.

Both analyses use DHS weights and 1,999 full-frame stratified Rao–Wu PSU bootstrap replicates, keeping each woman’s histories together. These are unadjusted estimates. The first original ending is actionable; later interruptions include all reasons, including wanted pregnancy. Unknown states censor before their first occurrence. Monthly records cannot resolve within-month interruptions.

Reading the appendix

The index is each woman’s earliest eligible observed ending in the analysis window, not her first lifetime ending. Selection occurs before examining whether she returns. Women without a return remain in the first curve and do not enter the second. This sensitivity changes the weighting of histories; it does not replace survey-design adjustment.

Survival estimation assumes administrative censoring is noninformative for these marginal curves. Late returns have less observable post-return follow-up, and the two clocks should not be combined by multiplying their endpoint percentages. These are episode/history outcomes, not mCPR forecasts or causal intervention effects.
