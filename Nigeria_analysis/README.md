# Nigeria: discontinuation analysis

- Report: `Nigeria_discontinuation_analysis.html`
- Presentation: `Nigeria_discontinuation.pptx` — slides only, no presenter notes.
- R entry point: `Nigeria_final_html_analysis.R`
- Planning horizon: **2024 to 2025**.

## Current build boundary

The R file retains the original numerical analysis modules and adds the latest
planning calculations and an **incremental HTML builder**. The tested revision
build reproduces the saved report's tables using an existing validated HTML
layout and fitted numerical outputs. Unchanged chapters and figures are retained
from that layout. This is **not a verified single-command raw-IR-to-entire-report
rebuild**. The presentation is a saved deliverable and is not generated by R.

## Inputs and commands

The revision build needs R packages `jsonlite`, `digest`, and `abind`, plus
Python 3 with `lxml`. `--packages` lists dependencies for the wider numerical
module collection. No personal input locations, credentials, microdata or fitted
model objects are bundled. `revision_inputs/` contains the aggregate point
estimates, joint bootstrap draws and metadata needed by the incremental build.

```sh
Rscript Nigeria_final_html_analysis.R --validate
Rscript Nigeria_final_html_analysis.R --run=prepare --project-root=work/raw --ir-file="$DHS_IR_FILE"
```

Preparation validates the authorized IR and constructs chronological calendars,
episodes and model inputs. It does not fit every downstream model. The original
stages remain available through `--list` and `--run=MODULE_NAME`.

The revised HTML command uses the included aggregate `revision_inputs/` by
default. It contains `planning_point.rds`, `planning_replicates.rds` and `planning_metadata.rds`. The saved-report build expects 500 survey bootstrap
replicates. It recomputes the revised planning summaries from those draws; these
are frozen analytical inputs, not a fresh fit to an IR supplied at render time.

```sh
Rscript Nigeria_final_html_analysis.R --run=build-html --project-root=work/build
```

The rebuilt report is written to `work/build/output/Nigeria_discontinuation_analysis.html`. Its validation
manifest records table comparisons, planning arithmetic, retained section/figure
coverage, and the incremental-build boundary. Checked inputs are not overwritten.
Use `--run=build-planning` for numerical summaries alone, `--python` to select
Python, or `--revision-inputs` to supply replacement growth-assumption JSON.
Use `--statistics-dir` to replace the included aggregate numerical inputs and
`--base-html` to select a different validated report layout.

## Definitions

Modern-method discontinuation excludes EC. EC remains in all-women mCPR.
Potentially actionable causes are method failure, wanting a more effective
method, bleeding changes, other side effects/health, and access/cost/convenience.
Partner/spousal disapproval is a separate group, excluded from actionable events.
Other endings remain competing events rather than being removed from denominators.

Main planning uses first-year, historical duration-aware, and AFT probabilities
and treats actionable original-method endings as losses. Switching/restarting
sensitivities are separate. Growth and population assumptions are fixed; the
same reference user cohort is retained across growth scenarios. Counts divided
by the projected outcome-year WRA, multiplied by 100, give mCPR pp contributions.

The IR preparation preserves weights, strata, PSUs, repeated-episode links,
delayed entry and censoring. Individual numerical modules document their survey
inference methods and model-specific restrictions. Archived alternative models
are retained for provenance; running every module blindly is not a validated
replacement for the documented analysis sequence.
